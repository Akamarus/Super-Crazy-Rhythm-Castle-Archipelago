# Super Crazy Rhythm Castle Archipelago setup — v0.15

1. Install `scrc.apworld` into Archipelago custom worlds.
2. Restart Archipelago Launcher after replacing the world.
3. Generate a **new** seed from the included YAML.
4. Host that newly generated seed; older generated seeds retain their old slot data and datapackage.
5. Run RhythmCastleAP **v0.67.58** with Hub6 Area Access routing enabled.

v0.15 forces Roots as the starter area, retains Weed Killer and cartridge randomization, and adds Plant Pipes plus the Level 3 Frog/Hippo source/completion split.
