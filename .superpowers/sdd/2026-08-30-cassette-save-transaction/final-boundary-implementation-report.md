## Scope

The client now observes exact `SaveDataRequestProcessor` selection, creation, and state-build mutations, queues managed-only boundary signals, and stabilizes the selected slot plus public native save-state pointer on the Unity keeper before activation.

#### Native write timing and public completion event

Fresh slot-4 testing then reached the exact public `PersistSaveChangeBundleRequest(DEFAULT, URGENT)` route but timed out twice without reporting success. The slot-4 redundancy files nevertheless rotated twice, exactly ten seconds apart during those confirmation windows. Installed metadata and native disassembly established that the request semantics were correct: `DEFAULT=1`, `URGENT=0`; `SaveDataRequestProcessor.ProcessRequest(PersistSaveChangeBundleRequest)` persists the selected player's requested bundle and marks an urgent write; and successful result processing advances the public write timestamp before clearing `RequiresWriteToDisk` and `HasChanges`.

The failure was the client's outer timing boundary. `SaveDataManager.InitiateBatchedWriteJob` supplies a one-second lead delay, while every `WriteSaveAsyncJob` has its own ten-second timeout and batched jobs execute sequentially. The game supports four regular player slots and can batch two global jobs plus four player jobs. A client deadline of ten seconds from request submission therefore expired before even one complete worst-case native write path could publish its result, and it could expire much earlier than a queued full batch. The second cassette verified while the first transaction was active, advanced the work revision, and caused the old timeout path to submit a combined second wave even though the first completion was still indeterminate.

The transaction now installs the established public `HandleEvent(PlayerSaveWriteCompletedEvent)` hook during plugin load, before cassette configuration or any possible persist submission. The active transaction is keyed by the authoritative save generation, epoch, UI slot, and processor-state pointer.
