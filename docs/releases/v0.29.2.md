# v0.29.2 — Cell Tower escape fixes

**October 22, 2026. Client 0.76.2 / APWorld 0.29.0 (unchanged).**

## Fixed

- Cell Tower Access now keeps the return gate from the Central Mainframe room toward the Cell Tower phone usable, including its interaction, before the native level-attempt requirement is met.
- Leaving that room toward Lobby before Fish Tears delivery now returns the player safely to Music Lab, avoiding the upper-Lobby hand-blocker trap. After delivery, the normal route remains subject to existing area ownership checks.
- These repairs do not complete quests, grant items, send checks or change generated progression rules.

## Updating

Close the game and install **RhythmCastleAP-v0.76.2.zip**, retaining its included licenses. Keep your configuration, current seed and associated save. APWorld remains **0.29.0**; the unchanged APWorld download is included for convenience. No regeneration or tracker update is required for this client patch.

## Validation and scope

Both reported escape routes passed targeted user gameplay testing. The release contains the accepted native-interaction repair with a version-label update. Native-reference tests cover exact condition validation, idempotence, wrong flags/classes and failed writes; existing routing regressions are also covered. Full release validation is recorded in [testing](../TESTING.md).

Separate investigation confirmed early Violance did not prevent Old Tom's note in the tested post-nectar state, and the Cell Tower Star Eater did not require Cold Storage completion after leaving and returning. Complete prerequisites are not yet isolated, so generation logic remains unchanged.

Intermittent performance stalls, extended-session/multiplayer coverage and remaining native-rule uncertainties remain in [known issues](../KNOWN_ISSUES.md). This release does not claim to resolve those reports.

See the [AI disclosure](../AI_DISCLOSURE.md) and [gate acceptance record](../testing/2026-10-22-hub-escape.md).

Release validation: all 45 client regression projects passed, the Release build completed with zero warnings/errors, repository validation passed, and all 10 packaging tests passed. The APWorld asset is reused byte-for-byte from v0.29.1.
