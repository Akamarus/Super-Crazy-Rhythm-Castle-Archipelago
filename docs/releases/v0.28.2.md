# v0.28.2 - Generation and Multiworld Compatibility

**APWorld v0.28.2 / Client v0.75.13 - September 29, 2026**

This APWorld-only update fixes compatibility and seed-generation failures found
by Ionium APTests. The game client is unchanged.

## Fixed

- Fixed APWorld loading failures caused by declaring the reserved `random` option.
- Removed unsupported starting-area choices. Roots remains the supported start;
  standard YAML `random` still works, and `validated_random` retains legacy value 0.
- Improved reverse-fill ordering for Stars, Music Lab points, song unlocks,
  Car Battery and Old Game Data to prevent reported generation dead ends.
- Fixed restricted checks rejecting filler from other games. They now accept
  filler/traps from any world while continuing to exclude progression and useful
  items. Progression-safe checks still accept progression from other games.
- Updated option descriptions, documentation and regression coverage.

## Validation

- 205 Ionium unit tests and all 150 local regression tests passed.
- All 14,500 fuzz runs passed across 11 variants, including 500 Universal Tracker
  checks, with zero failures or timeouts.
- All reported failing seeds were reproduced and repaired.
- Independent code review found no blocking correctness issues.

The index CI remains authoritative; browser results do not constitute index
approval. This is not a live 1,900-player test.

## Updating

Install the new **scrc.apworld** on the computer generating seeds or running
Universal Tracker. Keep your player YAML in the location required by your tracker
setup. Existing client v0.75.13 users do not need to replace game DLLs. The same
client archive is included for new installations.

Item/check IDs and schema 19 are unchanged. Existing seeds and saves remain
compatible; this update does not rewrite their placements. Generation repairs
apply to newly generated seeds.
