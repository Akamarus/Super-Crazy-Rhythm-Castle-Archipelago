# v0.29.0 — Cassette Bundles, Movement and Access Rules

**APWorld 0.29.0 / Client 0.76.0**

October 12, 2026 release.

## Added

- Optional randomized cassette bundles: `individual` (default), `pairs`, or `triples`. Each seed chooses its own groups, preserved across reconnects and Universal Tracker reconstruction. All cassette source and medal checks remain available.
- Bundle notifications and recent-item history identify the component songs.

## Fixed and improved

- Corrected Montage animal update timing without forcing a 50 FPS cap. The user accepted the improvement at normal high frame rates.
- Made the Regular/Pro Change selector usable before completing Level 1, including the initial save-to-hub transition.
- Improved item delivery readiness, deferred retries and native inventory verification so receipts can arrive without restarting. Pair-bundle receipt, deposit, immediate song selection and persistence after restart were verified in gameplay.
- Corrected Roots phone-booth presentation so the early portal does not obscure the Gecko and Weed Killer interactions.
- Allowed Music Lab reward chests to be opened when their vanilla cartridge reward is already owned. The Bloody Tears chest was verified while carrying Bloody Tears.
- Added a Star check before native level-entry side effects to prevent a failed entry from leaving the entrance unavailable until an area reload. This specific recovery case still needs live acceptance.
- Removed obsolete movement experiments and the temporary F9 frame-rate test; retained F8 movement capture. Display mode and frame-rate preferences remain native, with no forced fullscreen or frame cap.
- Repaired generation capacity for excluded checks by consolidating Music Lab point denominations when needed, preserving all 180 points, 66 Stars and other items.

## Access rules and Universal Tracker

- Lobby Access independently opens Boring Room, Minim Tower and The Vault, retaining each level's own Star gate.
- Plunger use requires Lobby Access and Plunger; Lobby Star Eater additionally requires its configured Star threshold.
- Corrected direct access to the Plunger, Bees, Frying Pan and Smooch pickups.
- Bucket Minion trade requires Roots Access and Hip Glasses without unrelated campaign completion.
- Corrected the Demolition Certificate source to use Boring Room rather than Demolition Training.
- Removed Central Mainframe from bee-variant access requirements while retaining each ordinary base route, Cell Tower Access and Hypno Pan.
- Added the Cell Tower return route for Fish Tears delivery while retaining the native Act 4 award requirement.
- Added the Lobby return entrance to Lift Quest and its cassette sources, preserving Roots Access and the level's own Star gate. Combo Bucket conversion still requires its inputs.
- Corrected Royal Corridor Star Eater access to area access plus its configured Star threshold.
- Required Plant Pipes for Level 15, Level 16's higher ratings and explicitly for Cold Storage. Level 22 retains Plant Pipes as a required logical route.
- Loneliness and Party Non Stop retain Hypno Pan.
- Improved tracker slot-data validation and cassette-route handling; expanded the prerequisite audit so inherited requirements are visible.

## Compatibility and installation

- Archipelago 0.6.8 generation and Universal Tracker 0.2.32 were tested.
- Install `scrc.apworld` in the Archipelago installation used by the generator and Universal Tracker, then restart those programs.
- Install the client ZIP following the setup guide before playing a bundled seed. Individual-cassette seeds retain schema 19; bundled seeds use schema 20 and require Client 0.76.0.
- Existing seeds retain their item placements, bundle mappings and Star gates. Updated logic does not regenerate an existing seed or guarantee that older placements satisfy newly tightened requirements.
- Follow the normal Universal Tracker setup, including its player YAML requirements where applicable; this release does not claim that YAML files are unnecessary.
- Packaging retains third-party license notices and excludes game assemblies and local logs. Original project code is MIT licensed.

## Validation

- 190 APWorld tests passed.
- 54 official AP 0.6.8 generation cases passed across difficulties, Star goals, cassette modes, exclusions and mixed-game sessions, with independent collection through Victory.
- Universal Tracker matched the world rules in 12 worlds and 1,888 inventory states.
- The client regression suite contains 42 projects; the release build is verified without installing over the running game.
- Both distributable archives passed the release packager's validation.

Automated consistency checks do not establish every native route; gameplay acceptance and remaining limitations are listed separately.

## Known issues and deferred testing

- Cold Storage and Cell Tower Star Eater story prerequisites need further investigation; deferred at the user's request.
- School Trip's Plant Pipes requirements and the Gold/On the Way cassette alternatives remain under review.
- Higher King Ferdinand ratings depend on late-game Gecko content that is not fully modeled. Those checks remain filler-only and are not guaranteed reachable.
- Bunker Keycard, Notepad, Data Stick and Demon Key work remains outside the completed AP-item/check scope; conservative Bunker/Demonic assumptions remain.
- Native Hypno Pan crafting alternatives are not comprehensively represented in item logic.
- Intermittent song/windowed/Combo Bucket performance and movement outside the accepted Montage case may still occur.
- Triple bundles, other delayed-item scenarios, Star-blocked entrance recovery, and the newer Lobby callback readiness paths need further live coverage.
- The revised tracker passed offline engine comparisons; a fresh live UI comparison remains useful.

## Next

Gather feedback on the updated release and prioritize remaining performance, delivery and native-route reports. Cold Storage/Cell Tower Star Eater testing remains deferred.
