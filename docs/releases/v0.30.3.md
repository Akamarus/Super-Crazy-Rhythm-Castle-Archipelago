# v0.30.3 — Super Nectar logic correction

APWorld **0.30.2** · unchanged game client **0.77.2**

`Cell Tower - Deliver Super Nectar` now requires Hypno Pan in generation and Universal Tracker. The old rule checked the base campaign routes but omitted the ability required by their Bee Mode nectar routes, so the tracker could show the delivery too early.

All other prerequisites, Star gates, item/location IDs and slot-data schemas are unchanged. Existing rooms keep their item placements.

## Updating

Replace `scrc.apworld` on the computer generating seeds or running Universal Tracker, then restart Archipelago/Tracker. The corrected tracker rule works with supported existing seeds. Client 0.77.2 does not need reinstalling; its ZIP is the unchanged download from v0.30.2.
