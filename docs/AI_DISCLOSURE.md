# AI disclosure

AI has been used extensively in this project. OpenAI Codex has assisted with the Python APWorld and C# game client, debugging, automated tests, code analysis, documentation, and release notes. Substantial portions of the implementation and fixes were written by AI; its role has gone beyond autocomplete or occasional assistance.

The maintainer directs the project, defines features and game logic, tests the integration in-game, reports incorrect behavior, and decides what to release. Human validation includes repeated gameplay tests and completed randomized playthroughs. This is not a claim of comprehensive human source-code review. Automated tests and AI code reviews are not substitutes for that review.

The maintainer remains responsible for the releases shared with the community and for addressing reported problems. This disclosure will be updated if the tools or development process change.

For the next public update, post and pin this disclosure in the implementation's Discord thread. This repository document alone does not constitute a pinned Discord disclosure.
