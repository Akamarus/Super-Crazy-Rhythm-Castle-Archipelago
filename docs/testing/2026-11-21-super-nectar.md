# Super Nectar delivery rule — November 21, 2026

Release v0.30.3: APWorld 0.30.2, unchanged game client 0.77.2.

## Report and cause

During a Hard/30-Star sync, Universal Tracker marked `Cell Tower - Deliver Super Nectar` available before Hypno Pan was received. The source rule checked completion routes for campaign levels 15, 2 and 11, but none of those base routes required Hypno Pan. The separate `Nectar Party - Completion` and `Act 1B: Nectar - Completion` rules already required it for Bee Mode.

Generation and Tracker reconstruction share this source rule. The missing prerequisite therefore affected progression placement as well as display. The report does not establish that a generated seed was unbeatable.

## Change and compatibility

Add Hypno Pan to the delivery's item requirements. Retain the existing route, access and Star prerequisites. No IDs, options, client code or slot-data schemas change. Updated Tracker rules correct availability for supported existing seeds, but cannot change items already placed by a running room.

The client ZIP is reused byte-for-byte from v0.30.2. This APWorld release does not include separate local client candidates.

## Verification

- Before the correction, both the native-source prerequisite test and a new Tracker reconstruction regression failed when Hypno Pan was removed from otherwise sufficient inventory.
- With the correction, both regressions pass, including availability after receipt and unavailability after removal. Existing area dependency checks remain covered.
- The full working-copy APWorld suite passed all 202 tests after repairing a stale Git worktree link. The repository had moved under Desktop/Old; the original history was retained. The previous packaging failure was an environment problem, not a skipped test.
- The isolated release source passed all 202 APWorld tests, all 19 packaging/tool tests, repository validation and `git diff --check`.
- The allowlisted packager built and validated APWorld 0.30.2. Its payload contains the reviewed Python files and license notices, with source provenance in `DISTRIBUTION.json`.
- Actual AP 0.6.8 generation used the unchanged Hard/30-Star/Plant-Pipes/triples YAML alongside ChecksFinder and DLCQuest. All three players' goals were beatable.
- Actual Universal Tracker v0.2.32 loaded the packaged APWorld and reconstructed two schema21 worlds: one generated by the corrected package and one generated with the previously published APWorld. In each case, sufficient inventory without Hypno Pan hid the delivery; adding Hypno Pan revealed it; removing Hypno Pan hid it again. Generated Star thresholds were preserved.
- The only integration warnings concerned the optional compiled location-store speedup and creation of an isolated default host configuration. Packaging negative tests intentionally exercise duplicate ZIP entries.

Local logs and generated packages are kept outside the repository. Native gameplay behavior is unchanged and was not retested for this APWorld-only correction.
